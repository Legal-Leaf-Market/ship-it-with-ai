Learned the hard way

Five rules. Five real stories.

The tools change every few months. These don't. Every rule came from something that went wrong on a live site.

01

The AI forgets. The guide file doesn't.

Every lesson goes into one plain file the AI reads at the start of every session. A mistake gets written down once, with the reason, so it never happens twice.

1 filethat turns a forgetful assistant into one that knows your business

02

Measure the outcome, not the first step.

An automatic Pinterest feed made 40 Pins in a few hours. Twelve hours later they had zero views. One setting was telling Pinterest not to show them.

0 viewson 40 Pins that "worked"

03

New things go in switched off.

Seven new shop partners went onto the site hidden from visitors until each one was tested. Only one actually worked. Nobody ever saw the six broken ones.

1 of 7new partners actually worked

04

Your voice is a rule, not a vibe.

The tells that make text read like a machine wrote it went into the guide file as a hard rule, with the reason. The AI cleaned the whole site in one request.

90tells removed across 25 files in one pass

05

Read the output before you publish it.

A "plushies" feed looked perfect on the page. Reading every item found handbags, a rug and trainers, because shops call anything soft "plush".

26%of the feed was not plushies
